# Changelog

## 1.0.0 (first public release, not yet published)

- Bring your own AI: your own Claude Code (found automatically), Claude API, OpenAI, Groq, OpenRouter, Ollama or any OpenAI-compatible server.
- Free, offline live transcription with the Windows speech recognizer; Azure Speech optional with your own key.
- Keys stored only on your PC, encrypted with Windows DPAPI. No server, account or telemetry.
- `--screenshot-mode` start option for documentation and testing.
- Fixed: duplicate shortcut warning at start, Settings × closing the app, shortcut list showing the wrong keys.
